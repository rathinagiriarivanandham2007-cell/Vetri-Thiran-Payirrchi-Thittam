PocketSmart AI — standalone website
====================================
Files:
- index.html: complete website in one file; includes HTML, CSS, JavaScript.
How to run:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. No Python, npm, server, or API key is required for the local demo.

Features:
- Responsive landing page
- Home, party, and jewelry budget planners
- In-browser budget allocations
- Download/copy generated budget plan
- Built-in demo chatbot
- All styling and logic included in index.html

Important limitations:
- This is a standalone front-end demo. It works in a browser but is not automatically published on the internet.
- The chatbot is rule-based, not a live Gemini model.
- Product/service prices are illustrative estimates. There are no live Amazon, Flipkart, IKEA, Swiggy, Zomato, or OYO integrations.
- For a genuinely online public website or live Gemini responses, deployment and a secure backend/API integration are needed. Never put a secret Gemini API key in client-side JavaScript.
